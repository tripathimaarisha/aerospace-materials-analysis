# Aerospace Materials: Python Visualisation

**Tools:** Python, NumPy, Matplotlib

## Overview
Exploratory visualisations related to aerospace materials:
- Density versus yield-strength comparisons for selected alloys.
- Conceptual low-temperature toughness profiles.
- A synthetic precipitation-hardening/ageing curve.

## Scientific scope and limitations
The alloy values in the comparison plot are the values used in the exploratory source code and must be verified against reliable datasheets or primary literature before quantitative use. The toughness profiles and ageing curve are synthetic illustrations, not measured data or fitted alloy-specific models.

## Run
Open `aerospace_materials_visualisation.ipynb` in Google Colab or Jupyter. Dependencies: `numpy`, `matplotlib`.
